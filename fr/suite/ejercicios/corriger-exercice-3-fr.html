Exercice nº 3

Sur le Prélude nº 4 en mi mineur, op. 28, de Frédéric Chopin (1839) — domaine public.
Matériel de l’exercice © 2026 Mario Maurano. Tous droits réservés.

Ce que vous allez faire : ouvrir dans le Player un fichier MIDI du Prélude qui contient des fausses notes volontaires, les trouver à l’oreille, la partition à côté de vous, et les corriger avec le copiste. Pour finir, vous enregistrerez votre version corrigée de trois façons : l’œuvre entière, une seule main et un passage de mesures.

Combien de temps : une trentaine de minutes. Ce qu’il vous faut : les fichiers de cette leçon (Preludio Nº 4 Op28 - E min (para corregir).mid et le PDF de la partition), le COSMIC KEYBOARD ouvert pour le son, et l’Exercice nº 2 déjà fait.

Les déplacements du copiste

En accord pythagoricien, chaque note a sa place exacte, et le copiste la déplace par de vrais intervalles, pas par touches :

±TTon. Un ton entier vers le haut ou vers le bas (Do → Ré).
±LLimma, le demi-ton diatonique : le nom de la note change (Mi → Fa, Do → Si).
±AApotome, le demi-ton chromatique : le nom de la note reste, l’altération change (Fa → Fa♯).
±KComma (23,46 cents) : la note voisine à un comma (La♭ ↔ Sol♯). Ce sont deux notes différentes.
Un ton = un limma + un apotome. C’est pourquoi « monter d’un demi-ton » a deux chemins qui ne sonnent pas pareil : avec L, le nom de la note change ; avec A, c’est l’altération qui change.

PREMIÈRE PARTIE — TROUVER ET CORRIGER

SUR LES IMAGES : les cercles orange indiquent où regarder ou cliquer.

1 · Chargez le fichier MIDI dans le PLAYER

Ouvrez le Player depuis le Cosmic Keyboard et déposez le fichier Preludio Nº 4 Op28 - E min (para corregir).mid sur la zone de dépôt. Écoutez-le en entier avec ▶, la partition PDF devant vous. Quelque chose sonne-t-il bizarrement ?

2 · Déplacez-vous dans le Score Roll

  • Molette de la souris : monte et descend dans les hauteurs.
  • Maj + molette : avance ou recule dans le temps.
  • Ctrl + molette : zoom avant ou arrière, autour du curseur.
  • Cliquer-glisser : déplace la vue lorsque le zoom est actif.
  • Double-clic sur un endroit vide : retour à l’œuvre entière.
Zoomez d’abord. Quand l’œuvre entière est visible, la molette et le glissement n’ont nulle part où aller : zoomez avec Ctrl + molette et, à partir de là, tout se déplace.

Sous le rouleau, la règle des mesures numérote chaque barre de mesure comme dans la partition (l’anacrouse est la mesure 0), et l’horloge vous indique toujours mesure:temps. La piste verte est la main droite et l’orange la main gauche.

Un clic sur une note ouvre le copiste : son nom, sa fréquence exacte et les boutons pour la déplacer. Avec ♪ listen, vous l’entendez seule.

3 · La première erreur

Une note de la mélodie est plus haute que ce qu’indique la partition. Trouvez-la en comparant avec le PDF.

IndiceElle se trouve dans la mesure 5, sur le temps 4. C’est un demi-ton diatonique : la note juste porte un autre nom.
SolutionIl indique C5 (Do5) et la partition indique B4 (Si4). Cliquez dessus puis −L : elle descend d’un limma et change de nom. Écoutez-la.

4 · La deuxième erreur

Une autre note de la mélodie a perdu son altération. Cherchez un dièse manquant.

IndiceElle se trouve dans la mesure 17, entre les temps 1 et 2. C’est un demi-ton chromatique : le nom de la note reste.
SolutionIl indique D5 (Ré5) et la partition indique D♯5 (Ré♯5). Cliquez dessus puis +A : elle monte d’un apotome, le nom de la note reste.
Vérification : écoutez de nouveau tout le Prélude. Si les deux notes corrigées ne vous gênent plus, c’est juste. Les notes que vous avez touchées sont marquées comme éditées dans le copiste.

5 · Découvrez le comma

Cette étape ne corrige rien : elle sert à entendre quelque chose qu’un clavier tempéré ne permet pas d’entendre. Dans la mesure 3, temps 4, la main gauche a un G♯3 (Sol♯3). Ouvrez-le dans le copiste.

  1. Écoutez-le avec ♪ listen.
  2. Appuyez sur −K. Il indique maintenant A♭3 (La♭3) : le nom est monté de Sol à La, mais le son est descendu d’un comma. Écoutez-le.
  3. Appuyez sur +K pour revenir au Sol♯.
Lequel des deux tire vers le La au-dessus ? Sol♯ est la sensible : il est plus haut et veut monter. La♭ est une autre note, un comma plus bas, qui veut descendre. Sur un piano, c’est la même touche ; ici, ce n’est pas la même note. Laissez-le sur Sol♯, comme le demande l’harmonie.

DEUXIÈME PARTIE — ENREGISTREZ VOTRE VERSION

6 · L’œuvre entière

  1. Dans l’en-tête du Score Roll, bouton ⭳ export → Export by instrument…
  2. Laissez les deux pistes cochées et la plage sur Work.
  3. Save MMF. Le fichier se télécharge avec le nom des pistes.

7 · Une seule main

La même chose, mais décochez l’une des deux pistes : seulement la verte pour la main droite, ou seulement l’orange pour la gauche. Enregistrez les deux, l’une après l’autre. Elles servent à travailler chaque main séparément, ou à les ouvrir dans le Score comme des parties distinctes.

8 · Un passage : mesures 13 à 19

  1. Trouvez la mesure 13 sur la règle. Clic droit exactement sur sa barre de mesure → Set A here.
  2. Trouvez la barre de la mesure 20 (la fin de la 19). Clic droit → Set B here. La section est ombrée entre A et B.
  3. ⭳ export → Export by instrument… La plage propose maintenant une option de plus : A–B section. Choisissez-la, cochez les pistes voulues et Save MMF.

CONSEIL : zoomez avec Ctrl + molette avant de placer A et B : le clic tombe alors exactement sur la barre de mesure. S’il a glissé, faites glisser le petit drapeau A ou B à sa place.

Vérification : votre dossier de téléchargements contient maintenant plusieurs fichiers .mmf : l’œuvre corrigée, chaque main et le passage. Ouvrez-les dans le Score (MENU FILES → IMPORT MMF) et vérifiez que chacun contient ce que vous avez choisi.

Félicitations : vous avez corrigé et enregistré votre propre copie

Dans l’Exercice nº 4, vous ouvrez l’œuvre corrigée dans le Score et vous achevez de l’écrire : nuances, liaisons, ligatures et les détails qu’un fichier MIDI n’apporte jamais.
